> AIOffice 职场通关 · 法律AI工作台 —— 面向法律从业者的本地优先 AI 办公工具。
> 法条查询、案例检索、法律计算、文书匿名、AI 工作台，一站搞定日常工作。

**绝大部分功能免费使用**：安装后即可直接上手，仅少数进阶功能需要激活解锁。

## ✨ 核心功能

| 模块 | 说明 |
|------|------|
| **AI 对话** | 直接提问；可勾选「检索法条/案例/备忘录」让 AI 带着你的数据回答；「深度思考」开关先推理再回答 |
| **连接器（MCP）** | 预置法律数据库（元典 / 北大法宝 / 威科先行）、联网搜索、识图等，填 API Key 一键安装 |
| **AI 工作台** | 智能体模式：AI 自己查资料、写文书、跑脚本；内置「中国法律专家团」（8 专家角色 + 40 法律技能） |
| **法条查询** | 内置 9538 条常用法条，关键词搜索 + 高级筛选 + 文档视图 |
| **案例检索** | 搜索案例库；「判决书入库」可把 PDF 判决书解析进库 |
| **法律计算** ⭐ | **13 个法律与财务计算器**：诉费、民间借贷本息、违约金/逾期利息、交通事故及人身损害赔偿、劳动纠纷、刑期、日期、大写金额、个税、房贷、通用贷款、存款、退休年龄 |
| **文书匿名** ⭐ | 自动识别姓名、身份证号、手机号、地址等敏感信息，一键匿名导出 DOCX；全程本机处理 |
| **图片识字（OCR）** | 图片/扫描 PDF 识别、截图 OCR；PDF 转 DOCX / MD / 图片 |
| **番茄时钟 / 日程管理 / AI 备忘录 / 思维导图** | 专注计时、任务日历、笔记写作、案情导图 |
| **数据管理** | 加密导入导出、LPR 刷新、向量索引管理 |

## 📦 安装

- **Windows**：下载 `.exe` 安装程序，双击按向导完成安装（未签名程序的安全提示为正常现象）
- **macOS**：下载 `.dmg`，拖入「应用程序」文件夹

安装包通过 **Release** 页面发布（本目录下 `安装包/` 为整理暂存区，不随仓库上传）。
